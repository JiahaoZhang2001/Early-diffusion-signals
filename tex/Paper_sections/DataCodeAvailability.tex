Replication code, manuscript sources, and instructions for reproducing the analyses are available at
\href{https://github.com/JiahaoZhang2001/Early-diffusion-signals.git}{\texttt{JiahaoZhang2001/Early-diffusion-signals}}.
This thesis uses publicly released rumor-cascade datasets, including FibVID and Twitter15/16. Because these data include social-media records that may be subject to platform terms, redistribution limits, and rehydration requirements, the repository does not re-host raw tweet content. Instead, it provides preprocessing scripts, feature-construction code, analysis scripts, generated manuscript assets, and run instructions for reproducing the reported results after users obtain the original released datasets from their respective sources and place them in the expected directory structure.
The repository identifies the scripts used for the Twitter15/16 benchmark, the main FibVID analysis, the time-window robustness checks, and the supplementary native-graph veracity analysis.
