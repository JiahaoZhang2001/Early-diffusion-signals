Replication code for all analyses and figures is available at
\href{https://github.com/JiahaoZhang2001/Early-diffusion-signals.git}{\texttt{JiahaoZhang2001/Early-diffusion-signals}}.
The study uses publicly released rumor-cascade datasets, including FibVID and Twitter15/16. To respect platform terms, redistribution limits, and possible rehydration requirements, I do not re-host raw tweet content in the repository. Instead, the repository provides preprocessing scripts, feature-construction code, manuscript sources, and run instructions for reproducing the reported analyses once users obtain the original released datasets from their respective sources and place them in the expected directory structure.
The repository also documents which scripts reproduce the benchmark pipeline, the main FibVID analysis, the time-window robustness checks, and the supplementary native-graph veracity analysis.
